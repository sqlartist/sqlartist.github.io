what: "Acorn's sturdy cream computer, built for the BBC's Computer Literacy Project. It was in nearly every British school."
---

If you learned to program at school in the 80s, you probably did it on one of these. Elite was born on it. Acorn's engineers later designed the ARM chip, which now runs almost every phone on the planet, so that classroom computer has a very long shadow.
