what: "Pages of program code printed in computer magazines for readers to type in by hand, line by line."

This is how many of us learned to program, mostly by learning to find our own typing mistakes. One wrong character on page four meant the game wouldn't run, and you had no idea where to look. I was convinced I needed to become a fast typist.
