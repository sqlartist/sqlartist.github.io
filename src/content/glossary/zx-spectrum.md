For a generation of British kids this was the first computer in the house, and the reason so many of us ended up working with them. It had eight colours, one beeping speaker and a memory smaller than this paragraph's web page, and it still felt like the future. I eventually built one inside SQL Server, so it's fair to say it never quite left me.
